## 🚀 معرفی پروژه
پروژه **Itachi Community** یک ربات اختصاصی دیسکورد است که برای مدیریت جوامع بزرگ طراحی شده است. این ربات با بهره‌گیری از جدیدترین قابلیت‌های Discord API (منوهای کشویی، دکمه‌ها و امبدها) نیاز به تنظیمات پیچیده و دستی را از بین برده و تمام کانفیگ‌ها را از طریق داشبوردهای گرافیکی داخل خود دیسکورد انجام می‌دهد.

---

## ✨ قابلیت‌های کلیدی

### 🛡️ سیستم امنیت و آنتی‌اسپم پیشرفته
* **فیلتر هوشمند لینک‌ها:** تفکیک دقیق بین لینک‌های دعوت دیسکورد (Discord Invites) و لینک‌های وب‌سایت‌های عادی.
* **الگوریتم Sliding Window:** جلوگیری قطعی از اسپم پیام با سیستم تشخیص هوشمند و مدیریت حافظه موقت.
* **داشبورد مدیریت امنیت:** تنظیم چنل‌های مجاز و لیست سفید (Whitelist) برای نقش‌ها و کاربران خاص به صورت زنده.
* **مجازات‌های خودکار:** اعمال تایم‌اوت‌های شخصی‌سازی شده (مثلاً ۲۴ ساعت برای تبلیغات غیرمجاز).

### 🎫 سیستم تیکتینگ مدرن
* **داشبورد کانفیگ زنده:** مدیریت دسته‌بندی‌ها، نقش‌های پشتیبانی و کانال‌های لاگ بدون نیاز به کپی کردن آیدی‌ها.
* **تولید رونوشت (Transcript):** ذخیره کامل تاریخچه مکالمات تیکت در قالب فایل متنی پس از بسته شدن.
* **مدیریت دسترسی:** اضافه شدن خودکار اعضای تیم پشتیبانی به تیکت‌های جدید.
* **رابط کاربری تعاملی:** استفاده از دکمه‌ها برای ساخت، بستن، بازگشایی و حذف تیکت.

## 🛠️ پیش‌نیازها
برای اجرای این ربات به موارد زیر نیاز دارید:
* **Node.js:** نسخه 16.9.0 یا بالاتر
* **MongoDB:** دیتابیس لوکال یا کلاستر (MongoDB Atlas)
* **Discord Bot Token:** دریافت شده از پورتال دولوپرهای دیسکورد
